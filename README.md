# Production Chat Platform

A production-grade real-time cloud-native chat application built using Kubernetes and DevOps best practices.

## Tech Stack

### Frontend
- React.js
- Tailwind CSS
- Socket.IO Client

### Backend
- Node.js
- Express.js
- Socket.IO

### Database
- MongoDB

### Cache
- Redis

### DevOps & Cloud
- Docker
- Kubernetes
- Helm
- GitHub Actions
- ArgoCD
- Prometheus
- Grafana

## Features

- Real-time chat
- JWT Authentication
- Kubernetes orchestration
- Horizontal autoscaling
- CI/CD pipeline
- Centralized logging
- Monitoring dashboards
- GitOps deployment

## Architecture

Frontend → Backend → Redis → MongoDB
